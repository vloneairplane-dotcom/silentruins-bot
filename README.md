# SilentRuins Bot

## Environment variables

BOT_TOKEN=your_bot_token
PEXELS_API_KEY=your_pexels_key
ADMIN_IDS=123456789
CHANNEL=@songsandscars
TIMEZONE=Asia/Tehran

Send an MP3 directly to the bot from an admin account.
It will be saved into `music/` and become available to automatic posts.

Commands:
- /start
- /id
- /post
- /pause
- /resume
- /stats
- /songs
- /panel
